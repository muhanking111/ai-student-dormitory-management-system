# 用户手册

## 登录与会话

本地演示使用 `.env` 中配置的 bootstrap 管理员。登录成功后，菜单和操作按钮会按后端返回的角色与权限显示；刷新页面会恢复服务端会话。菜单隐藏不是安全边界，接口仍执行 Sa-Token、RBAC、对象范围和业务状态校验。

若后端不可用，登录页会显示服务不可用状态并保留重试入口；会话失效时返回登录页。不要把 Cookie、Token 或密码粘贴到截图、issue 或日志附件。

## 内置角色

| 角色 | 主要范围 |
| --- | --- |
| `ADMIN` | 业务、系统管理和首期 AI 管理能力；高敏审计正文和公开知识发布仍需要单独权限 |
| `DORM_MANAGER` | 宿舍、学生、入住、卫生和公告日常管理 |
| `REPAIRER` | Dashboard、维修读取和维修处理 |
| `VIEWER` | 获授权业务只读页面 |

演示脚本只自动创建 `.env` 指定的 bootstrap 管理员。其他角色可由管理员在用户与权限页面按需创建，不在仓库中保存固定演示密码。

## Dashboard

首页展示宿舍、学生、入住、维修、费用、卫生和公告的固定指标，以及趋势、风险概览和待处理事项。自然语言查询只映射到固定指标执行器，不生成 SQL。

- 风险摘要是确定性业务规则信号，不是学生评价或预测画像。
- “查看建议”进入来源页面，“进入审批”仅在提案目标和权限满足时出现。
- 数据不可用与真实 0 值分开显示，不使用静态成功回退。

## 宿舍与入住

- 楼栋、宿舍、床位：查看和维护资源；宿舍缩容只允许删除空闲床位。
- 学生信息：分页查询、创建、编辑、删除和导入校验。
- 入住申请：提交、审核、拒绝并分配空闲床位。
- 宿舍分配与退宿：按状态机更新学生、床位、入住记录和宿舍容量统计。

遇到容量冲突、已占用床位、重复活动入住或非法状态迁移时，系统会拒绝写入并显示业务错误，不应绕过校验直接修改数据库。

## 维修、费用、卫生与公告

- 维修：创建、筛选、指派、相邻状态流转、完成和维修记录。
- 费用：创建账单、部分缴费、完成缴费和收费记录；不连接真实支付网关。
- 卫生：检查记录、评分、备注和只读历史。
- 公告：草稿、编辑、发布、撤回和发布排序；已发布公告不能退回草稿。

所有普通业务写都经过后端权限、输入、对象和状态机校验。演示数据为合成 fixture，不要录入真实学生、宿舍或维修隐私信息。

## AI 助手

助手支持全局或页面上下文提问、SSE 流式输出、停止、重试、反馈和引用展开。

- 无可靠来源时明确拒答，不把常识补写成校内事实。
- 引用被撤权时不展示正文；对象授权失败不泄露资源是否存在。
- 输入区持续提示不要输入姓名、学号、手机号或凭据。
- 关闭运行中的助手需要确认，停止后保留已生成内容。

本地演示使用确定性 Fake provider，证明的是前后端、MySQL、Redis、HTTP/SSE、权限、预算和审计链路，不是真实模型效果。

## 知识管理

知识来源包含分类、ACL、版本、校验和、摄取任务和激活状态。空 ACL 默认拒绝；来源 Owner 不能独自完成需要分权的复核。版本变更或 ACL 撤销后，旧引用不得回放未授权正文。

## 维修分诊与公告起草

- 维修分诊只从当前业务可用维修人员中形成建议，不能编造用户 ID。
- 公告 AI 只生成纯文本草稿，不能直接发布。
- 低置信、无引用、数据已变化、权限不足或审计不可用时，提案或批准按钮会被阻断。

首期允许形成业务提案的 action type 只有 `REPAIR_ASSIGN` 和 `NOTICE_CREATE_DRAFT`。

## 风险中心

风险中心只覆盖入住、维修、卫生和欠费的确定性运营信号。用户可以查看规则证据、AI 解释、降级状态和人工处置时间线。AI 不自动处罚、不修改学生状态，也不做纪律、心理、健康或信用画像。

## 审批与审计

审批页展示目标、当前值与建议值、影响范围、权限、引用、as-of、版本/hash 和过期时间。

- `PENDING_APPROVAL`：有权用户可复核。
- `STALE / EXPIRED`：禁止批准，必须回来源页面刷新并重新预览。
- `APPROVED`：仅表示审批完成，不代表业务成功。
- execution `SUCCEEDED`：业务 Service 已确认写入成功。
- `NEEDS_REVIEW`：业务执行结果需要人工核对，不能显示成功。`NEEDS_RECONCILIATION` 单独表示模型成本对账，不是业务执行状态。

审计页默认显示脱敏元数据和 hash 链。读取必要正文需要独立权限、理由和再次审计；无权限时只显示安全范围不可用。

## 常见状态

| 状态 | 含义与处理 |
| --- | --- |
| 加载中 | 等待当前请求，不重复提交 |
| 空数据 | 当前筛选没有可见记录，不代表服务失败 |
| 权限不足 | 返回首个可访问页面或显示受限状态，联系管理员分配最小权限 |
| 数据过期 | 刷新业务事实并重新生成预览 |
| 后端不可用 | 保留当前输入，检查本地服务后重试 |
| AI 降级 | 继续显示确定性规则或业务事实，不冒充模型成功 |
| 审计不可用 | 阻断需要审计的 AI 写链，普通人工业务按既有边界处理 |

## 移动端与键盘

移动基线为 `390x844`，使用折叠侧栏、单列内容和至少 `44x44` 的触控目标。表格在窄屏使用横向容器或移动列表。常用控件支持键盘焦点，弹窗和助手关闭后焦点返回触发位置；启用 `prefers-reduced-motion` 时减少非必要动效。
